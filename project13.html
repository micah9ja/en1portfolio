Project 13

1D Reinforcement Color Searcher

With this project, Dr.E expanded our knowledge of machine learning by introducing us to reinforcement learning. We developed a robot and webpage that let us train the robot by assinging points to various colors, letting the robot know which colors were "bad" and which ones were "good" (aka which ones led it closest to the intended target color, which was green.) Then we would deploy our robot in the testing environment to see how well our training did. We then also experimented to see if it would still work even if we switched the colors around but still kept the values, or if we changed the values but kept the colors in the same orientation etc. Overall I learnt alot about machine learning from these past projects and it made me really interested to learn more.
