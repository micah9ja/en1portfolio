Project 5: Spirograph Drawing Machine

Dr.E assigned us to create a spirograph drawing machine using only LEGO pieces from the SPIKE Prime kit. At first what really tripped me up was how to keep an arm spinning while also having a pivot point so that only one end rotates with the gear attatched to the motor. I then figured out that making it fixed at one end would allow the other end to rotate freely. I then did the same thing with the other arm, and added a "holder" for the dry erase marker. I think added a spinning base for the notepad to be on, because I realized that since the motors are spinning at the same speed, that alone wouldn't make a pattern similar to those in actual spirographs. In the end I am happy with the result!
